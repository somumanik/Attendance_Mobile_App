Savior Biometric SQL Server → Node/Express → this UI

Data Flow

Savior Biometric Machines │ (continuous punch writes) ▼ Microsoft SQL Server → dbo.tblemployee (master) dbo.tbltimeregister (processed daily attendance) dbo.machinerawpunch (raw punches / fallback) ▲ │ mssql (read-only pool) — credentials only in backend .env Node.js + Express REST API (never expose SQL to browser) ▲ │ fetch() + polling every 60s / on section open This Portal (Employee + HR UI)

SQL used by backend (verified sources only)

-- Employee master (only real columns) SELECT paycode, empname, presentcardno, dateofbirth, dateofjoin, sex, ismarried, qualification, experience, designation, departmentcode, companycode, active, leavingdate, telephone1, e_mail1, address1, pincode1, emphoto FROM dbo.tblemployee WHERE ISNULL(active,'Y') = 'Y'; -- Attendance register (processed punches) SELECT paycode, punchdate, intime, outtime, workedhours, status FROM dbo.tbltimeregister WHERE paycode = @paycode AND punchdate BETWEEN @from AND @to ORDER BY punchdate DESC; -- Raw biometric punches (fallback / rebuild) SELECT cardno, punchdate, punchtime, devicename FROM dbo.machinerawpunch WHERE punchdate >= @from; -- Today's birthdays (DAY + MONTH only, birth year ignored) SELECT paycode, empname, presentcardno, departmentcode, designation, dateofbirth FROM dbo.tblemployee WHERE MONTH(dateofbirth) = MONTH(GETDATE()) AND DAY(dateofbirth) = DAY(GETDATE()); -- Upcoming birthdays (30 days, year independent) SELECT paycode, empname, dateofbirth, DATEDIFF(day, CAST(GETDATE() AS date), DATEFROMPARTS(YEAR(GETDATE()), MONTH(dateofbirth), DAY(dateofbirth))) AS days_left FROM dbo.tblemployee; -- Work anniversary (dateofjoin, DAY + MONTH) SELECT paycode, empname, dateofjoin, YEAR(GETDATE()) - YEAR(dateofjoin) AS years_completed FROM dbo.tblemployee WHERE MONTH(dateofjoin) = MONTH(GETDATE()) AND DAY(dateofjoin) = DAY(GETDATE());

Marriage Anniversary — separate HR table (do NOT alter dbo.tblemployee)

CREATE TABLE dbo.HR_MarriageAnniversary ( id INT IDENTITY(1,1) PRIMARY KEY, paycode VARCHAR(30) NULL, -- dbo.tblemployee.paycode presentcardno VARCHAR(30) NULL, -- dbo.tblemployee.presentcardno anniversarydate DATE NOT NULL, createddate DATETIME DEFAULT GETDATE(), updateddate DATETIME DEFAULT GETDATE(), importedby VARCHAR(50) NULL, CONSTRAINT FK_Marr_Emp FOREIGN KEY (paycode) REFERENCES dbo.tblemployee(paycode) );

Excel workflow: File → Preview → Validate (paycode / presentcardno match) → Matched / Unmatched / Invalid summary → Confirm Import → Summary. Unmatched aur invalid rows kabhi import nahi hote.
