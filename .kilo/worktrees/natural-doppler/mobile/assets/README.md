# Mobile App Assets

This directory contains static assets for the mobile app.

## Required Assets

### Icons (for app.json)
- `images/icon.png` - 1024x1024 app icon (used for app store)
- `images/adaptive-icon.png` - 1024x1024 adaptive icon (Android)
- `images/favicon.png` - 48x48 favicon (Web)

### Splash Screen
- `images/splash.png` - 2732x2732 splash screen image

## Placeholder Status
These assets need to be created before production build.
For development, Expo will use default icons.

## Color Scheme Reference
The app uses a modern light theme:
- Primary: #2563EB (Blue-600)
- Secondary: #0D9488 (Teal-600)
- Background: #F8FAFC (Slate-50)
- Surface: #FFFFFF (White)

Icons should work well on light backgrounds.
